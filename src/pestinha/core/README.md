# `pestinha/core/`

> Gerado por `ferramentas/gerar_readmes.py` a partir das docstrings. Não edite à mão: rode o script.

Cérebro e regras puras: rede neural, emoção, homeostase, memória, condicionamento, física e protesto. Sem Qt e sem API do sistema, para ser testável em qualquer lugar.

**Pode importar de:** módulos compartilhados (e dos módulos compartilhados). A regra é verificada por `tests/test_arquitetura.py`.

| Arquivo | O que faz |
|---|---|
| `conditioning.py` | Ele aprende a reagir ANTES do que costuma acontecer com ele. |
| `emotion.py` | Da atividade dos neurônios motores para UMA emoção. |
| `episodic.py` | O que aconteceu de verdade, e o que fazer da próxima vez. |
| `homeostasis.py` | Variáveis internas que o pet tenta manter em equilíbrio. |
| `motor.py` | A atividade dos neurônios motores controla o corpo DIRETAMENTE. |
| `nervous_system.py` | A rede neural pulsada do pet (neurônios de integração e disparo com vazamento). |
| `physics.py` | Corpo 2D do pet: gravidade, inércia, rotação, quique e pouso. |
| `protesto.py` | A insatisfação do pet e o estágio em que ele está. |
